This repository contains the materials shown during the practical sessions of the course [Data Science in Chemical Engineering](https://onlineservices.polimi.it/schedaincarico/schedaincarico/controller/scheda_pubblica/SchedaPublic.do?&evn_default=evento&c_classe=865137&lang=IT&__pj0=0&__pj1=8fb3736558d68f72e55686ef6d6328ed)
taught at Politecnico di Milano by Professor [Alessandro Stagni](https://www.creckmodeling.polimi.it/team/alessandro-stagni/).

## Course Structure
The repository is organized into 12 main modules:

1. [**Hands On Python**](practicals/01-Hands%20On%20Python/) - Introduction to Python programming
2. [**SVD**](practicals/02-SVD/) - Singular Value Decomposition
3. [**PCA**](practicals/03-PCA/) - Principal Component Analysis
4. [**Unsupervised Machine Learning**](practicals/04-Unsupervised%20machine%20learning/) - Clustering and dimensionality reduction
5. [**Supervised Machine Learning**](practicals/05-Supervised%20machine%20learning/) - Classification and prediction
6. [**Regression**](practicals/06-Regression/) - Linear and non-linear regression techniques
7. [**Model Selection**](practicals/07-Data%20visualization/) - Methods for choosing and validating models
8. [**Neural Networks**](practicals/08-Neural%20Networks/) - Fundamentals of neural networks
9. [**Deep Learning**](practicals/09-Deep%20learning/) - Advanced neural network architectures
10. [**Reduced Order Models**](practicals/10-Reduced%20Order%20Models/) - Model order reduction techniques
11. [**Physics Informed Models**](practicals/11-Physics%20informed%20models/) - Integration of physical principles with data science
12. [**Pandas and Imbalanced Datasets**](practicals/12-Pandas%20and%20Imbalanced%20datasets/) - Data manipulation and handling imbalanced data


## Installation and Setup
Clone the repository:
```bash
git clone https://github.com/Riccaraccio/Data-Science.git
```

Create the **conda** environment
```bash
conda create -n datascience python=3.12
```

Install within the conda environment the necessary packages
```bash
conda activate datascience
pip install .
```
